# App de Clima em Python

Aplicativo desktop com interface gráfica moderna que consulta a temperatura atual de qualquer cidade em tempo real utilizando a Open-Meteo API.

## Tecnologias Utilizadas
* Python
* CustomTkinter (Interface Gráfica)
* Requests (Consumo da API)

## Como Executar

1. Certifica-te de que tens o Python instalado.
2. Instala as dependências necessárias no terminal:
   ```bash
   pip install customtkinter requests
